# Meu Site no GitHub Pages

Site estático pronto para publicar no GitHub Pages.

## Como usar

1. Suba este projeto para um repositório no GitHub.
2. Garanta que a branch principal se chame `main`.
3. Ative GitHub Pages em `Settings > Pages`.
4. Selecione `GitHub Actions` como fonte, se ainda não estiver selecionado.

## Personalização

- Edite os textos em `index.html`.
- Ajuste cores e layout em `styles.css`.
- Troque o título automático em `script.js` se quiser.
